# Análisis de anuncios de venta de coches

Aplicación web interactiva construida con Streamlit que permite explorar 
un conjunto de datos de anuncios de venta de coches en EE. UU.

## Funcionalidad
- Visualización de la distribución del odómetro mediante un histograma interactivo.
- Visualización de la relación entre el odómetro y el precio mediante un gráfico de dispersión.
- Casillas de verificación para mostrar u ocultar cada gráfico.
